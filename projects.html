Implementation

GeoDetect

Implementation

Rate Limiter Lab

Show backend learners how request limits behave under bursts.

Implementation

A Flask UI and JSON endpoint exercise fixed windows, a sliding-window log, and a token bucket. A lock protects shared limiter state within the process.

Scope and limitations

Counters are in memory, so restarts reset them and separate workers have independent state.

Late Submission Predictor

Explore how recorded submission patterns relate to assignment deadlines.

Implementation

The script labels historical timestamps against a deadline, trains a classifier, and compares it with a baseline using stratified evaluation.

Scope and limitations

Timestamp-derived inputs can encode the deadline relationship. The experiment describes historical records and does not establish advance forecasting ability.
